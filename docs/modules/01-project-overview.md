# Project Overview

## Enterprise

Enterprise Technology Solutions (ETS) is a fictional engineering and technology services organization used to provide business context for this Windows administration lab.

## Project Purpose

The purpose of this project is to develop practical enterprise Windows administration capabilities through the design, operation, and documentation of a virtual infrastructure environment.

## Project Objectives

- Understand how Windows infrastructure supports business operations.
- Administer Windows Server in a VMware environment.
- Develop Active Directory administration skills.
- Configure and troubleshoot DNS, DHCP, Group Policy, and file services.
- Introduce PowerShell automation.
- Practice monitoring, backup, recovery, and operational documentation.
- Produce professional artifacts suitable for a technical portfolio.

## Administrative Approach

Infrastructure changes will follow a design-first process:

1. Document the existing state.
2. Identify business and technical requirements.
3. Design the proposed change.
4. Assess risk and dependencies.
5. Implement a controlled change.
6. Validate the result.
7. Document lessons learned.

## Lab Constraint

The host computer has 16 GB of RAM. Virtual machines will therefore be deployed incrementally, and only the systems required for the current lab will normally run at the same time.

## Existing and Future Environments

### Existing inherited environment

- Domain: corp.enterpriseit.local
- Domain Controller: SERVER01

This environment was created during an earlier training course and is being used to practice assessment and administration.

### Future ETS environment
